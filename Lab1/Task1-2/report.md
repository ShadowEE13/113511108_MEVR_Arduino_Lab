### 1. 實驗目標
- 控制RGB三色LED
- 用可變電阻輸入類比訊號(0~1023, 輸入腳位 10bits)，換作輸出類比訊號至LED上，以改變藍色LED的顏色(0~255, 輸出腳位 8bits)
- 用按鈕、序列埠輸入改變狀態，疊加不同顏色至原LED上，以依序改變顏色(藍>紫>綠)

### 2. 設備與元件
- Arduino Uno 開發板 x 1
- USB Type-B 傳輸線 x 1
- 個人電腦（已安裝 Arduino IDE）x 1
- 三色LED x 1
- 220 ohm 電阻 x 3
- 可變電阻 10k x 1
- 按鈕 x 1

### 3. 操作說明與成果
1. **燒錄程式**：使用 USB 線連接 Arduino Uno 至電腦，開啟 `Task1-2.ino` 並點擊「上傳」。
2. **轉動可變電阻**：轉動可變電阻，改變接收腳位的電壓，讓藍色LED可以有明亮變化。
3. **按下按鈕**：按下按鈕後狀態改變，點亮紅色LED，整體呈紫色。
4. **序列埠輸入**:在序列埠輸入1後改變狀態，點亮綠色LED，整體呈白色。
5. **操作影片**：請參閱同目錄下 `video/Task1-2.mov` 之實際操作畫面。
